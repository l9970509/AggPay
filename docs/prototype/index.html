直达失效时的兜底路径

正常情况下点卡片会直接落到微信收付款页。若某次微信改版导致直达失效，按下面路径手动进入：

1进入微信，点底部「我」
2进入「服务」→「收付款」
提示：支付宝始终直达，不受影响。

微信也能一键出码

本应用已能直接跳到微信收付款页。若某次微信更新导致直达失效，可以用微信自己的入口兜底，效果一样。

1长按桌面微信图标，点「服务卡片」
2选择「收付款」样式，添加到桌面
3以后点亮屏幕，点卡片直接出付款码
更短的方案：微信收付款页底部有「添加到桌面」，点一下生成直达图标。
